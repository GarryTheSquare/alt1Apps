Alt1 Toolkit apps

You can add these apps to your alt1 menu, or open them in the browser if you prefer. The browser versions are not able to pull certain numbers for you from the game, but their main functionality will work.

Tools

  • Metronome

    A visual metronome to overlay your game window to help with tick manips and npc timings. Based on OSRS Visual metronome plugin

    Add to Alt1 Open in browser
  • Nemi Forest

    Shows the image from the newest r/NemiForest post. It does currently not check if the status is live though, but this rarely happens for me

    Add to Alt1 Open in browser

Calculators

The calculators are a bit messier due to the large amount of input possibilities, they are correct for my testing, but let me know if something is off

  • Archaeology Tracker

    Archaeology training guide, artefact tracker, restoration materials and collection overview.

    Add to Alt1 Open in browser
  • Ritual Materials

    Necromancy ritual material calculator — inks, candles, focus objects and sub rituals if making everything from basic mats.

    Add to Alt1 Open in browser
  • Thieving Tables

    Searchable list of everything thieving chests, stalls and pickpocketing can get you.

    Add to Alt1 Open in browser
