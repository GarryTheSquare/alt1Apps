Alt1 Toolkit apps

Click Add to Alt1 to install a tool (opens the Alt1 client), or Open in browser to just view it as a web page. You need the free Alt1 Toolkit installed for the install links to do anything.

Tools

  • Metronome

    A visual metronome — a counter that loops 1 to N on a game-tick interval, in a small window over the game.

    Add to Alt1 Open in browser
  • Nemi Forest

    Shows the image from the newest r/NemiForest post.

    Add to Alt1 Open in browser
